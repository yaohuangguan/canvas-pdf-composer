One portable PDF

Built for the material Canvas scatters everywhere.

Course structure

Keeps the module order, item titles, contents and source links instead of flattening everything into a random download folder.

Slides and files

Captures Canvas file previews, direct PDFs and Google Slides exports, then appends them to the course PDF in module order.

Local-first

No Canvas password is copied into the extension. It uses the session already open in your browser and does not upload course files to a Composer server.

Install it.

Download

Click “Download for Chrome” and unzip the file.

Open extensions

Go to chrome://extensions and turn on Developer mode.

Load unpacked

Choose the unzipped Canvas PDF Composer folder, then open a Canvas Modules page.
